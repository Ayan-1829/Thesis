Before we start

Why this matters

“I trained a model and got 95%.” Every ML examiner has heard this a thousand times, and the next question is always the same: “So what did you learn?”

An ML thesis is a careful question about learning, with fair baselines, honest evaluation and an explanation of why it works. Almost every field now uses ML; few students learn to research it properly.

This chapter maps the field, its methods, data and venues, with thesis ideas at three levels.

Part 1 of 12

What machine learning research studies

Machine learning (ML) studies algorithms that learn patterns from data and improve with experience, instead of following hand-written rules. Research asks how to learn more accurately, from less data, faster, more robustly and more fairly — and why methods work.

The field

Typical research problems

ProblemExample thesis question
Learning from little labelled dataDoes semi-supervised learning with 10% labels match full supervision on a local dataset?
Generalisation and robustnessHow much does accuracy drop under distribution shift (new hospital, new season), and which method reduces it?
EfficiencyCan knowledge distillation make a model 5× smaller with less than 1 point loss?
Imbalanced and noisy dataWhich loss or sampling strategy works best when the rare class is 2% of the data?
InterpretabilityDo SHAP explanations agree with domain experts on which features matter?
FairnessDoes a credit model treat applicants from different regions equally, and can re-weighting fix it?
Tabular and time-series predictionDo gradient-boosted trees beat deep models for crop-yield forecasting?

Most ML theses fail at the edges of this pipeline — leaky splits, untuned baselines, one random seed — not in the model. Chapter 8 covers these in detail.

Methods

Key methods to know

Classical models

Linear and logistic regression, SVMs, decision trees, random forests, gradient boosting (XGBoost, LightGBM) — still the best for many tabular problems.

Neural networks

MLPs, CNNs for grids (images), RNNs and transformers for sequences; trained with gradient descent and back-propagation.

Unsupervised learning

Clustering (k-means, DBSCAN), dimensionality reduction (PCA, t-SNE, UMAP), autoencoders.

Self-supervised and transfer learning

Pre-train on unlabelled data, then fine-tune — the default for images and text today.

Methods

Key methods to know (cont.)

Ensembles and regularisation

Bagging, boosting, dropout, weight decay, early stopping: ways to reduce overfitting.

Explainability

Feature importance, SHAP, LIME, saliency maps — to understand and debug predictions.

  • Use k-fold cross-validation for small data.

Thesis ideas

StarterBenchmark ML models on a local tabular dataset

Compare logistic regression, random forest, XGBoost and an MLP on, for example, crop yield or student performance data, with proper CV and SHAP analysis.

StandardLearning with few labels

Measure how semi-supervised or self-training methods perform as labelled data shrinks from 100% to 5%.

StandardRobustness to distribution shift

Train on one year or region, test on another; evaluate domain-adaptation methods.

StandardFairness audit

Measure group fairness metrics of a public model and test a mitigation method.

AmbitiousEfficient models for edge devices

Distil or quantise a model to run on a phone; measure accuracy, latency and energy.

Thesis ideas

Getting started in four weeks

  1. Week 1refresh the basics: linear models, overfitting, cross-validation; reproduce one tutorial
  2. Week 2pick a dataset; build a scikit-learn baseline end to end
  3. Week 3read 5 recent papers on your problem; note their baselines and metrics
  4. Week 4reproduce one paper’s main number; write a one-page idea
Pitfalls: tuning on the test set, accuracy on imbalanced data, one random seed, comparing with untuned baselines, ignoring simple models.

Worked example 1 of 2

Worked example 1

A student’s random forest gets 99% accuracy predicting loan default; 3% of loans default. What do you check?
Show the solution
Class imbalance (a model predicting “no default” always scores 97%), leakage (features recorded after the default, such as “collection calls”), the split (same customer in train and test). Report recall, precision and AUC-PR for the default class.

Worked example 2 of 2

Worked example 2

Turn “use deep learning for crop yield prediction” into a research question.
Show the solution
“Do LSTM models using weekly weather data predict district-level rice yield more accurately (lower MAE) than gradient-boosted trees using seasonal aggregates, when tested on a held-out recent year?”

Practice

Practice (1 of 2)

Try each one yourself first, then check the answer.

1. Name four typical ML research problems.
Show the answer
Learning from few labels, robustness to distribution shift, efficiency, imbalanced/noisy data, interpretability, fairness.
2. What is overfitting and how do you detect it?
Show the answer
The model fits the training data (including noise) but generalises poorly; training error is low while validation error is high or rising.
3. Which model family should always be a baseline for tabular data?
Show the answer
Gradient-boosted trees (XGBoost, LightGBM) — and a simple linear model.

Summary

Summary

  • ML research asks how to learn more accurately, from less data, robustly, efficiently and fairly.
  • Know classical models, neural networks, unsupervised, transfer and self-supervised learning.
  • Use public repositories (UCI, OpenML, Hugging Face, Kaggle) or local data; describe and split it carefully.
  • Evaluate with the right metrics, cross-validation, several seeds and strong baselines.
  • Top venues: NeurIPS, ICML, ICLR (plus AAAI, IJCAI, KDD); start with workshops and regional conferences.
  • Start by reproducing one paper’s main result.
